## New Method

```dart
abstract class ProfileService {
  // ... existing methods ...

  /// Resolves the signed URL for the avatar at [storagePath].
  ///
  /// Returns `null` if [storagePath] is null or empty.
  /// Implementations MUST cache the result for the duration of the URL's
  /// validity and MUST NOT call the signing endpoint more than once per
  /// cache entry per session (FR-005, FR-006).
  /// Implementations MUST proactively refresh the URL when it is within
  /// 5 minutes of expiry (FR-007).
  Future<String?> getSignedAvatarUrl(String? storagePath);

  /// Clears all in-memory caches owned by this service.
  ///
  /// Called by [ProfileManager.clearSession] on logout.
  void clearCache();
}
```

## `SupabaseProfileService` Implementation Notes

- `getSignedAvatarUrl`: checks internal `Map<String, _SignedUrlEntry>` before calling
  `Supabase.instance.client.storage.from('avatars').createSignedUrl(path, 3600)`.
- `clearCache`: clears the `Map<String, _SignedUrlEntry>` map.
- `updateProfile` (modified): after a successful avatar upload, calls `clearCache()` for
  the old avatar path entry only (so other cached URLs remain valid).
